## Deviations / friction
- The red commit abea539 contained the red.sh behaviour revert (non-test code): its red only covered the usage text. The PR declared it, so it's a suggestion, but review-pr has no instruction for "red commit contains implementation".
- /code-review ran forked in the background. Its notification came in while I was running test-init.sh. It found two real gaps I had missed: the retro step's absolute path without `cd <root>` (r2's own suggestion was incomplete: retro.sh cds to the toplevel of the cwd), and the TDD row's `git switch` with no target worktree. Lesson: when suggesting a path fix for a script, check whether the script cds on its own.
- The orchestrator's checkout was on a feature branch at 6dc40f1, behind origin/main. "Trusted checkout, on the base branch" is not enforced anywhere (orchestrate does not check it).
